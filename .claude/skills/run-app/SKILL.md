# Run App Skill

Use this skill when you need to run, test, or preview the web application locally.

## Instructions:
- Since `index.html` is a static web app, it can be opened directly in any browser (e.g., `start index.html` on Windows).
- Alternatively, run a simple local HTTP server:
  `python -m http.server 8000`
  then open `http://localhost:8000`.
