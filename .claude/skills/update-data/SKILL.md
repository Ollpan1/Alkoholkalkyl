# Update Data Skill

Use this skill when you need to update the drink database (`systembolaget.json`) from the source API.

## Steps:
1. Ensure Python is installed and accessible.
2. Run the update script:
   `python update_apk_data.py`
3. Verify that `systembolaget.json` is updated successfully with active products and APK calculations.
